# Acceptable Use Policy

**Last Updated:** 2026-09-06  
**Version:** v1.0  

## Prohibited Activities and Content

The following activities and content types are strictly prohibited on the platform:

1. **Illegal Activities:** Any unlawful services, fraud, fraudulent financial schemes, or prohibited material.
2. **Unauthorized System Access and Malware:** Developing or deploying malware/ransomware, phishing, credential harvesting, or unauthorized penetration testing without written system owner authorization. Only authorized defensive cybersecurity work is permitted.
3. **Secrets and PII Exposure:** Posting third-party personal information, passwords, private API keys, or infrastructure credentials.
4. **Intellectual Property Infringement:** Work violating copyright, trademark, or patent laws.
5. **Academic Dishonesty:** Commissioning assessed academic work intended to be misrepresented as one's own.
6. **Circumvention:** Posting public contact information in listings to bypass private matching.
7. **Emoji and Rich Formatting:** User content must remain professional, plain text without emoji sequences.
