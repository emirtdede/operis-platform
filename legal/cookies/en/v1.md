# Cookie Policy

**Last Updated:** 2026-09-06  
**Version:** v1.0  

## Strictly Necessary Cookies

The platform uses only **technically necessary cookies** required for security and core functionality. Advertising, profiling, and third-party ad tracking cookies **are strictly not used**.

Used cookies:
- `fp_session`: HttpOnly, Secure, SameSite=Lax session authentication cookie.
- `fp_theme`: User interface theme preference cookie (Light, Dark, True Black) to prevent layout flash.
